# Project Bootstrap Example

Request: “Continue this project, fix the registration flow and leave verifiable evidence.”

The agent declares capabilities; identifies repository, branch, status and effective rules; creates a goal contract; assigns implementation; collects the builder's diff and tests; obtains an independent reviewer verdict; integrates and updates authorized status; creates a handoff and successor handshake if the session changes; and declares `ACHIEVED` only after every gate passes.

Without separate agents, record the review as adversarial but not independent.
