# Project Bootstrap Example

Request: “Continue this project, fix the registration flow and leave verifiable evidence.”

1. The agent reads the harness and declares capabilities.
2. It identifies repository, branch, status and effective rules.
3. It creates a contract: corrected flow, relevant tests, review and observable validation.
4. The lead assigns implementation; the builder returns the diff and tests.
5. The reviewer inspects the actual diff and issues a verdict.
6. The lead integrates and updates authorized status.
7. If the session changes, it creates a handoff and the successor performs a handshake.
8. It declares `ACHIEVED` only when every gate passes.

If the platform does not support separate agents, record step 5 as non-independent adversarial review. The objective must not claim independent approval that did not occur.
