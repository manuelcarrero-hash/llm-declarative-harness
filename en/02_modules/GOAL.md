# Module: Durable Goal

Activate for a substantial and coherent outcome.

## Contract

Define the objective, completion evidence, scope, authoritative sources, boundaries, validations and checkpoints. `Done` must be observable, not merely a list of activities.

## Execution

Address the highest-value gap with the smallest authorized change; validate it; compare it against every criterion; record learning; and continue with a different strategy if the work does not converge.

## Closure

Use only `ACHIEVED`, `BLOCKED_EXTERNAL`, `DECISION_REQUIRED` or `AUTHORITY_REQUIRED`. Progress, a partial test or a created file does not constitute `ACHIEVED`.
