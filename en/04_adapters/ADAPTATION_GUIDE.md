# Model and Platform Adaptation Guide

Complete `CAPABILITY_PROFILE.template.yaml` with evidence. Do not infer tools from provider marketing.

Map durable files to a drive, repository or workspace; separate agents to actual subagents, processes or sessions; independent review to another agent without the builder's preferred verdict; context measurement to real token telemetry; approvals to a verifiable human pause; and traces to event, tool, handoff and result logs.

Bootstrap by reading the English entrypoint, manifest, core and activated modules. Copy templates only when they do not compete with existing sources.

Degrade honestly: without subagents, disclose adversarial self-review; without writes, use report mode; without telemetry, avoid percentages; without session creation, write a handoff and ask the user to open a clean session; without verifiable tools, label evidence `REPORTED` or `UNKNOWN`.

Run `../06_validation/CONFORMANCE_TEST.md` and publish exceptions.
