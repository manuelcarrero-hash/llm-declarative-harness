# Operating Contract

The user owns intent, material decisions and authority. The lead owns scope, checkpoints, evidence and integration. Workers execute bounded assignments but do not close the global goal. Independent reviewers inspect the actual work. Durable files, not chat alone, preserve project truth.

Cycle: identify project and rules; define objective and observable `Done`; choose a proportional team; execute the smallest useful checkpoint; validate; update authorized state or handoff; repeat to a strict terminal state.

Classify evidence as `OBSERVED`, `REPORTED`, `INFERRED`, `PLANNED` or `UNKNOWN`. Distinguish local, committed, pushed, reviewed, merged, deployed and user-validated.

When a capability is missing, preserve the semantic contract and disclose the degradation. Adversarial self-review is not independent review; qualitative context pressure is not telemetry; a written handoff is not a created successor session.
