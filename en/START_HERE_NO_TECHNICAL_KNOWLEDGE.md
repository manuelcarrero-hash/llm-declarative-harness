# Start here if you have no technical background

You do not need to code or understand AI terminology.

This harness is a folder of instructions and templates that helps AI work more reliably on large projects. It tells the AI how to define success, preserve progress, review work, continue in another chat and avoid claiming completion without proof.

It can help when AI forgets decisions, makes you explain everything again, loses track of the latest version, changes something without permission or says a project is finished while work remains.

Use it for apps, websites, books, courses, research and professional projects that take several conversations. You probably do not need it for a simple question, translation, short email or one-turn task.

## How to start

1. Give the model read access to this folder.
2. Copy the prompt below.
3. Describe your project in normal language.
4. Review what the AI proposes before authorizing changes.

> I want to work on a project using this harness. Read `en/00_READ_ME_FIRST.md` and then `en/HARNESS_MANIFEST.yaml`. Explain in plain language which parts you can actually use on your platform and which you cannot. Do not assume capabilities you do not have. Help me configure the project without overwriting existing files or taking actions I have not authorized.

The harness organizes work but does not make AI infallible or grant missing tools. You remain in control of publishing, deployment, deletion, permissions, spending and sensitive decisions.
